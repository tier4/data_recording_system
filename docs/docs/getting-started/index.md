## What is DRS?

The Data Recording System is a high-performance sensor data recording system designed for Co-MLOps platform. It runs on NVIDIA Jetson AGX Orin-based embedded ECUs and synchronously records data from multiple sensors including cameras, LiDARs, and IMUs.
